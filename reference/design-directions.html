Directions for your new base design

Each direction is the same screens with a different set of tokens: Ping's web inbox, Pocket on a phone, and a component kit. The screens are built the way the real library will be: every colour, font, radius and shadow is a token. Switching tabs swaps the tokens and nothing else. You can pick one, or mix them, e.g. Halo's surfaces with Ember's type.

How this becomes the library

Whichever direction you pick, the tokens move into the tokens package and these components become css + react components. Kotlin, AGS/GTK and ANSI outputs are generated from the same tokens (see the Ping Blueprint's design system section).

What's shared by all four

  • More air than Neutronic: 15px body text, 40px icon targets, 44px+ touch targets on the phone.
  • Light and dark are both first-class. Neither is the default.
  • Priority 1–5 and per-topic colours are tokens, so a topic looks the same on web, phone and desktop pop-ups.

Mixing is fine

Directions are bundles of separate choices: palette, type, shape language (radius, borders, shadows) and surface treatment (flat, outlined, glass). Tell me, for example, "Signal's type with Ember's colours" and I'll build the mix.

What I need from you

  • A direction, or a mix.
  • Anything you love or hate in what you see.
  • A name for the system. Some candidates: Ion, Flux, Arc, Prism.
